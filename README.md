# Feed de fotos estilo Instagram

Práctica de maquetación de un feed de publicaciones utilizando HTML y CSS.

## Tecnologías

HTML y CSS.

## Inicio rápido

```bash
git clone https://github.com/jm181987/Simple-Instagram-Photo-Feed-with-HTML-CSS.git
cd Simple-Instagram-Photo-Feed-with-HTML-CSS
```

Abre el HTML principal en el navegador o utiliza un servidor local.

## Seguridad y mantenimiento

- Comprueba los scripts y variables de entorno antes de desplegar.
- No publiques credenciales ni datos sensibles.
- Registra los cambios y problemas con pasos de reproducción.
